# Incumbents: Notion, OpenAI/ChatGPT, Anthropic/Claude — agent-built, self-updating personal workspaces (as of 2026-09-26)

Research note date: 2026-09-26. Source-quality legend: [P] = primary (vendor site/help center/changelog), [S] = secondary (press/blog/aggregator — verify before quoting). Several OpenAI primary pages (help.openai.com release notes, openai.com/index) returned HTTP 403 to the fetcher; for those, the claim is cited to the primary URL as shown in search snippets plus a secondary corroboration.

## Notion: can Custom Agents run on schedules/triggers, build/modify databases, pull from external sources, and what does it cost?

### Takeaway
Notion is the closest incumbent on "persistent structured workspace + scheduled agent": Custom Agents (Notion 3.3, 2026-02-24) run autonomously on schedules or event triggers and write into Notion pages/databases, with Mail/Calendar/Slack/Gmail and MCP connectors. But it is team-priced (Business/Enterprise seats + metered credits since 2026-05-04), and the output is Notion pages/databases, not bespoke per-tab UIs; no evidence of monitoring arbitrary websites the user visits.

### Cited Findings
- Timeline: Notion 3.0 ("Notion Agent", personal agent directed task by task) announced Sept 2025 (pre-2026; details may have changed) — [P: Introducing Notion 3.0](https://www.notion.com/blog/introducing-notion-3-0). Custom Agents shipped in Notion 3.3 on 2026-02-24 — [P: Notion 3.3 release](https://www.notion.com/releases/2026-02-24).
- Custom Agents "operate autonomously on schedules or event-based triggers" — e.g. monitoring Slack channels, incoming requests, calendar events — to generate responses and reports; use cases include Q&A, task routing/triage, daily standups/recaps, email drafting and inbox triage, scheduling — [P: Notion 3.3](https://www.notion.com/releases/2026-02-24).
- Trigger examples reported: Slack mention, new database row, weekly schedule, emails, calendar events, database changes — [S: eesel AI review](https://www.eesel.ai/blog/notion-ai-review); [S: Matthias Frank tutorial](https://matthiasfrank.de/en/notion-custom-agents-full-tutorial-use-cases-pricing-changes/).
- Data sources/tools: Notion docs and databases, Slack, Notion Mail & Calendar, third-party tools via MCP (Linear, Figma, HubSpot, FigJam); the 3.3 release page does not mention general web search or Gmail — [P: Notion 3.3](https://www.notion.com/releases/2026-02-24).
- Gmail: the personal Gmail AI connector is free to connect on all plans; once connected the Agent can search the inbox, draft and send, archive/trash, manage labels, unsubscribe — [P: Notion AI connector for Gmail](https://www.notion.com/help/notion-ai-connector-for-gmail); [S: eesel](https://www.eesel.ai/blog/notion-ai-connector-for-gmail). (Whether this connector is usable by *Custom* Agents vs. only the personal Notion Agent was not confirmed from a primary page — see Gaps.)
- Databases: release says agents "can create tasks and manage databases"; schema creation/editing not detailed — [P: Notion 3.3](https://www.notion.com/releases/2026-02-24).
- Notion 3.4 part 2 (2026-04-14): Custom Agents "35–50% cheaper to run" via cheaper models (GPT-5.4 Mini, Haiku 4.5); private Slack channel access; "upcoming" Teams/Google Drive/Salesforce integrations; n8n MCP integration for Custom Agents; Notion Agent gets Skills (saved reusable workflows), Calendar/Mail/Slack integrations; **AI Autofill** database property that "continuously enriches, extracts, and categorizes" rows; Salesforce and Box connectors — [P: Notion 3.4 part 2](https://www.notion.com/releases/2026-04-14).
- Pricing: Custom Agents are Business and Enterprise only; free trial through 2026-05-03; from 2026-05-04 they consume Notion credits bought by admins; credits are workspace-shared, reset monthly, don't roll over; agents pause when credits run out; notifications at 80%/100%; downgrading to Free/Plus disables Custom Agents; credits not purchasable via mobile app-store subscriptions — [P: Custom Agent pricing](https://www.notion.com/help/custom-agent-pricing?indexHtmlPath=index-web-en-US-0e192f14766ed7cd); [P: Buy & track credits](https://www.notion.com/help/buy-and-track-notion-credits-for-custom-agents).
- Credit price $10 per 1,000 credits — [S: Matthias Frank](https://matthiasfrank.de/en/notion-agent-pricing/); [S: DEV Community](https://dev.to/kanta13jp1/notion-custom-agents-goes-101000-credit-on-54-a-free-way-to-run-all-6-departments-7cj). One power user's workspace used 33,700 credits ($337) in a month; switching simple agents from Opus to Haiku cut cost ~80% — [S: Matthias Frank](https://matthiasfrank.de/en/notion-agent-pricing/).
- Business plan seat price: $20/user/month annual, $24 monthly — [S: eesel pricing](https://www.eesel.ai/blog/notion-pricing); [S: costbench](https://costbench.com/software/project-management/notion/).
- Frequent/scheduled agents burn more credits over time — [P: Custom Agent pricing](https://www.notion.com/help/custom-agent-pricing?indexHtmlPath=index-web-en-US-0e192f14766ed7cd).

### Inferences
- Floor cost for a solo consumer to get scheduled agents in Notion ≈ one Business seat ($20–24/mo) + usage credits (tens to hundreds of $/mo for many scheduled agents). That is team/B2B pricing, not consumer pricing — a real opening for a consumer product.
- Notion's "workspace" is generic pages/databases; the founder's differentiator would be per-tab purpose-built UIs (email triage board, job pipeline, etc.) generated and maintained by the agent, plus aggregation of arbitrary sites the user visits — neither is evident in Notion.
- Notion's positioning (Slack, HubSpot, Linear, Salesforce, admin controls) is squarely team/enterprise.

### Gaps
- No primary confirmation that Custom Agents can do open web browsing/scraping of arbitrary sites, or monitor sites on a schedule.
- Per-run credit consumption and any included credits per plan not found.
- Unconfirmed whether the Gmail connector (vs. Notion Mail) is available as a Custom Agent trigger/source.
- No info found on Notion releases after April 2026 (e.g., 3.5+) within the tool budget.

## OpenAI: Pulse, ChatGPT agent, Atlas, Apps, scheduled Tasks, and any persistent-workspace features in 2026

### Takeaway
OpenAI has moved fast and is now the most direct threat: Pulse was retired (June 2026) in favor of redesigned Scheduled Tasks (time- and, since 2026-08-25, event-triggered on Gmail/Slack/GitHub, plus web monitoring), and **ChatGPT Sites** (public beta 2026) lets users build hosted dashboards/web apps with their own database and scheduled refresh tasks — essentially "agent-built persistent dashboard" — gated to paid plans. Meanwhile ChatGPT agent and the Atlas browser were discontinued (Aug 2026), showing churn/instability in its consumer agent surfaces.

### Cited Findings
- **Pulse**: launched 2025-09-25 as a Pro-only ($200/mo) mobile preview, came to web 2025-10-29, never reached Free/Plus — [S: justinmckelvey.com](https://justinmckelvey.com/blog/chatgpt-pulse); [S: BleepingComputer](https://www.bleepingcomputer.com/news/artificial-intelligence/chatgpt-pulse-is-coming-to-the-web-but-no-word-on-free-or-plus-roll-out/).
- Pulse sunset: release notes (2026-06-17): "Pulse is being sunset as proactive updates move into scheduled tasks"; Pro users kept access 14 more days — [P: ChatGPT release notes (403 to fetcher; via search snippet)](https://help.openai.com/en/articles/6825453-chatgpt-release-notes); corroborated by [S: TestingCatalog on X](https://x.com/testingcatalog/status/2067321189362454952), [S: TechJack](https://techjacksolutions.com/ai-brief/agentic-ai-news-openai-launches-scheduled-tasks-in-chatgpt-a/), [S: prowlo](https://prowlo.com/blog/chatgpt-pulse-shut-down).
- **Scheduled Tasks** (relaunched 2026-06-17 with a dedicated Scheduled sidebar): one-off or recurring prompts for reminders, briefings, monitoring that can check the web or connected apps; limits reported: at most ~once per hour, auto-pause when you stop engaging, no voice/file uploads/Custom GPTs inside tasks; paid feature (Go, Plus, Pro, Business, Enterprise) — [S: usecarly](https://www.usecarly.com/blog/chatgpt-scheduled-tasks/); [S: analyticsinsight](https://www.analyticsinsight.ae/news/openai-shifts-from-ai-briefings-to-automation-with-scheduled-tasks-rollout). (Conflict: one secondary says Free users get 3 active tasks with once-daily recurrence — same usecarly search summary; unresolved.)
- Scheduled Tasks can "perform an action once, repeat it on a schedule or when an event occurs, or monitor for changes over time"; ChatGPT Work can keep projects moving while away, e.g. turning new Teams/Slack messages into updated docs or slides — [P: OpenAI, "ChatGPT is now a partner for your most ambitious work" (403 to fetcher; via search snippet)](https://openai.com/index/chatgpt-for-your-most-ambitious-work/).
- 2026-08-25: "ChatGPT scheduled tasks can now run when supported events occur in Gmail, Slack, or GitHub," with sender/subject filters and repo watching — [P: ChatGPT & Codex changelog](https://learn.chatgpt.com/docs/changelog).
- **ChatGPT Sites**: 2026-06-02 "Sites is now available in preview in the Codex app… create, save, deploy, and inspect websites, dashboards, internal tools, web apps, and games hosted by OpenAI"; custom domains added 2026-07-09 — [P: changelog](https://learn.chatgpt.com/docs/changelog). Public beta in ChatGPT for Pro, Pro Lite, Edu, Plus "over the coming days"; start in ChatGPT Work on web or Work/Codex in desktop app; use cases named: "live dashboards, project trackers, launch calendars…"; shareable to team or publicly via URL — [P: OpenAI announcement (via snippet)](https://openai.com/index/chatgpt-for-your-most-ambitious-work/).
- Sites stores data in its own Cloudflare D1 database and supports scheduled refresh tasks, so a public viewer doesn't need their own connectors; not on Free/Go, not in EEA/Switzerland/UK at launch — [S: GenAI Unplugged](https://genaiunplugged.substack.com/p/chatgpt-sites-vs-claude-artifacts).
- **ChatGPT agent**: removed in early August 2026 with no deprecation period; help center points to ChatGPT Work (multi-step tasks) and a cloud browser — [S: usecarly](https://www.usecarly.com/blog/chatgpt-agent-mode/); primary page [help.openai.com ChatGPT agent](https://help.openai.com/en/articles/11752874-chatgpt-agent) returned 403 — unverified directly.
- **Atlas**: OpenAI is deprecating Atlas and folding browser agentic capabilities into ChatGPT and Codex; Atlas stops working 2026-08-09 — [P: OpenAI announcement (via snippet)](https://openai.com/index/chatgpt-for-your-most-ambitious-work/); [S: Search Engine Land](https://searchengineland.com/openai-chatgpt-atlas-deprecation-482003); [S: nerova](https://nerova.ai/news/openai-retiring-atlas-browser-computer-use-moving-into-chatgpt-july-2026). (So Atlas "browser memories" — which was the closest thing to "aggregate sites the user visits" — is gone.)
- Browser replacements: Codex Chrome extension (2026-05-07) works "in parallel across tabs in the background"; cloud browser sign-in to supported websites (2026-08-25) — [P: changelog](https://learn.chatgpt.com/docs/changelog).
- Models: GPT-6 Sol and Luna in Codex/ChatGPT Work 2026-08-22; Luna available to Free/Go in desktop app — [P: changelog](https://learn.chatgpt.com/docs/changelog).

### Inferences
- ChatGPT Sites + event/scheduled Tasks + Gmail triggers already approximates the founder's concept (agent-built persistent dashboard, refreshed in the background). The gap is more UX than capability: Sites is framed as "publish a site/web app" inside Work/Codex (prosumer/work framing), not a unified multi-tab personal home curated by an agent.
- Hourly task floor and auto-pause on inactivity limit "always-on" monitoring; rapid product churn (Pulse, agent, Atlas all killed within ~12 months) is a trust weakness a focused product can exploit — but also a sign OpenAI iterates quickly into this space.
- With Atlas gone, OpenAI has no first-party "passively observe the sites the user visits" surface as of Sept 2026 (Chrome extension is task-driven).

### Gaps
- Could not fetch OpenAI primary pages (403) — exact date of the Work/Sites announcement post, and the Plus rollout completion for Sites, unconfirmed.
- Apps in ChatGPT / Apps SDK 2026 status not researched within budget (Apps SDK launched Oct 2025; may have changed).
- Memory integration with Sites/Tasks, per-plan Sites limits (number of sites, DB size, refresh frequency) not found.

## Anthropic/Claude: artifacts with storage, connectors, generative UI, Chrome, Cowork, scheduled tasks — can a consumer build a self-updating personal dashboard today?

### Takeaway
Yes, largely, on paid plans (Pro $20+): artifacts now support persistent storage (20 MB, personal or shared state), app connectors, and calling Claude from inside the artifact; scheduled tasks run in Anthropic's cloud (hourly/daily/weekly) with connectors. Weaknesses: the pieces are separate (a scheduled task produces task output; the artifact pulls live via the *viewer's* connectors rather than being written by the task), connector-backed artifacts can't be public, and artifact formats changed twice in Aug–Sep 2026.

### Cited Findings
- Artifact capabilities (current help page): edit via chat or in-template, "Connect your apps to an artifact" (Pro/Max/Team/Enterprise), data storage 20 MB text-only with personal or shared options, artifacts can call Claude directly; Free can create artifacts but has no app connections or storage; requires "Cloud code execution and file creation" enabled — [P: What are artifacts](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them).
- "Legacy artifacts" (pre-2026-09-16) remain functional but can't be newly created — i.e., a new artifact format launched 2026-09-16 — [P: What are artifacts](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them).
- Cowork "live artifacts" (made before 2026-08-19) are now legacy: still work, can't be edited in place; "When someone opens your artifact, it connects to their connectors and data sources"; "Shared artifacts use the viewer's access, not yours"; org-only sharing, no public links — [P: Use live artifacts in Cowork](https://support.claude.com/en/articles/14729249-use-live-artifacts-in-claude-cowork).
- An artifact that calls connectors can't be shared to a public link on any plan — [S: GenAI Unplugged quoting Anthropic docs](https://genaiunplugged.substack.com/p/chatgpt-sites-vs-claude-artifacts); [P: Share artifacts](https://support.claude.com/en/articles/9547008-publish-and-share-artifacts).
- **Cowork**: desktop-app tab beside Chat and Code; public beta Jan 2026 (macOS) / Feb 2026 (Windows), GA 2026-04-09; included in paid plans from $20/mo — [S: Vellum](https://www.vellum.ai/blog/official-claude-cowork-breakdown).
- **Scheduled tasks**: run remotely "even when your computer is asleep or the Claude Desktop app is closed"; Pro, Max, Team, Enterprise; cadence hourly/daily/weekly/weekdays/manual; same capabilities as Cowork tasks incl. connected tools, skills, plugins (Slack summaries, email filtering, web research); output appears in the Scheduled tasks section; cannot be tied to a local folder — [P: Schedule recurring tasks in Cowork](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork). Also available in "the new Claude experience that's rolling out gradually to Pro and Max" — [S: search snippet of support.claude.com](https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork).
- Developer equivalent: Claude Code "routines" (cloud cron agents) on Pro/Max/Team/Enterprise at claude.ai/code/routines — [P: Claude Code routines docs](https://code.claude.com/docs/en/routines).
- Memory: "Generate memory from chat history" in Settings → Capabilities — [S: XTrace](https://xtrace.ai/blog/how-to-manage-claude-memory).
- Claude in Chrome: extension with per-site permission toggles; users report agent-created tab groups accumulating across sessions — [S: usecarly comparison](https://www.usecarly.com/blog/claude-in-chrome-vs-openai-atlas/); [S: GitHub issue](https://github.com/Iris-Ares/Spotion/issues/44).

### Inferences
- A Pro user can today: ask Claude to build an artifact dashboard (with shared storage + Gmail/Calendar connectors) and a scheduled task that does daily research — this covers much of the founder's concept for technical-ish users. The friction is composition: the user must understand artifacts, connectors, scheduled tasks and Cowork as separate concepts; there is no single "my workspace with N agent-maintained tabs" object.
- Anthropic's artifact model (runs with viewer's connectors; no public link for connector artifacts) is privacy-safe but makes "background job writes into the dashboard" less natural than OpenAI Sites' own-database model (inferred; exact ability of a scheduled task to write into artifact storage not confirmed).
- Two format migrations in ~4 weeks (Aug 19, Sep 16 2026) suggest the surface is still in flux.
- Common weakness across all three: none passively aggregates the arbitrary sites a user browses (Atlas was the nearest and was killed); all are cloud-only (no local-first data); all gate background features behind paid tiers.

### Gaps
- Claude "Imagine" (generative UI research preview, Oct 2025, Max-only, pre-2026) — no 2026 status found; may have been folded into artifacts.
- Claude for Chrome 2026 availability/plan gating not confirmed from a primary source.
- Whether scheduled tasks can write to an artifact's persistent storage (i.e., true background-updated dashboard) is not documented in the pages fetched.
- Usage limits for scheduled tasks on Pro vs Max (how many tasks, cost against quota) not found.
